Política de privacidad

Última actualización: 6 de noviembre de 2026

Astel es un reproductor multimedia. No incluye contenido propio ni vende datos personales. Esta política explica qué datos trata la aplicación.

1. Datos que se guardan en el dispositivo

  • Datos de acceso al servicio de medios (dirección del servidor, usuario y contraseña): se guardan solo en el almacenamiento local de la app, para no tener que escribirlos cada vez. No se envían a Astel; se usan para conectar con el servicio que el usuario haya configurado.
  • Favoritos, historial, progreso de reproducción y ajustes: se guardan en el dispositivo.

2. Sincronización con el servidor de Astel

Si el usuario inicia sesión, los favoritos, el historial y el progreso de reproducción se sincronizan con el servidor de Astel para poder recuperarlos en otro dispositivo. La sincronización se asocia al nombre de usuario del servicio de medios y a un identificador aleatorio del aparato. No se sincronizan la contraseña ni la dirección del servicio.

3. Registro de acceso

Al entrar y al abrir la app con la sesión iniciada se envía al servidor de Astel: nombre de usuario, identificador del aparato, modelo, plataforma, versión de la app, dirección IP y User-Agent. Se usa para gestionar los accesos y prevenir abusos; no se usa para publicidad.

4. Informe de diagnóstico (opcional)

En Ajustes > Acerca de puede haber un botón para enviar un informe de diagnóstico. Solo se envía si el usuario lo pulsa. Incluye modelo del aparato, versión de Android, decodificadores, estado del reproductor y las últimas líneas técnicas. Antes de enviarlo se eliminan usuario, contraseña, URL del servicio y tokens. Se usa solo para resolver problemas técnicos.

5. Datos que no se recogen

  • No se piden nombre, correo, teléfono ni dirección.
  • No se usa publicidad, no se usa el identificador de publicidad y no se venden datos.
  • No se rastrea la ubicación.
  • No se accede a contactos, fotos ni archivos del dispositivo.

6. Servicios de terceros

  • El servicio de medios que configure el usuario recibe sus datos de acceso y las peticiones de reproducción, con su propia política de privacidad.
  • TMDB se usa para carátulas y fichas de películas y series; solo se envían búsquedas de títulos, no datos personales.

7. Menores y control parental

La app no está dirigida a menores. Incluye un control parental por PIN para ocultar las categorías que el usuario marque. El contenido disponible depende del servicio de medios del usuario.

8. Conservación y borrado

Los datos locales se borran al desinstalar la app o al limpiar sus datos. Los datos sincronizados se pueden borrar desde la propia app en Ajustes > Datos > Borrar datos sincronizados, o solicitando el borrado en el correo de contacto. Más detalles en la página de borrado de datos.

9. Contacto

Para cualquier duda sobre privacidad: jedohodev00@gmail.com

10. Cambios

Si cambia esta política, se publicará una versión nueva en la misma URL con la fecha de actualización.

Astel no incluye contenido propio. Reproduce el contenido al que el usuario ya tiene acceso con su servicio de medios.
